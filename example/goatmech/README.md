# GoatMech

Goat Breed Knowledge Base.

GoatMech records goat breeds: where each comes from, what it is kept for, and the features that tell it apart, with every claim quoted from its source.

GoatMech is a Mech: one validated YAML record per goat breed, a
LinkML schema, ontology-grounded identifiers, cited evidence with verbatim
quotes, and an append-only curation history. AI agents write most of it and
people review it through pull requests. It follows the pattern of
[DisMech](https://github.com/monarch-initiative/dismech).

## Layout

| Path | What it is |
|---|---|
| `data/goat_breeds/` | One YAML file per goat breed |
| `src/goatmech/schema/goatmech.yaml` | The LinkML schema. Root class `GoatBreed` |
| `src/goatmech/schema/mech_shared.yaml` | Discussion and Dataset classes, vendored from the Mech fleet |
| `src/goatmech/schema/history.yaml` | The curation history schema, vendored from the Mech fleet |
| `history/` | Append-only curation history, one file per session |
| `conf/oak_config.yaml` | Which ontology service checks which CURIE prefix |
| `cache/`, `references_cache/` | Term and source caches written by the validators |
| `curation/source_queue.tsv` | Ranked sources that feed curation |
| `research/` | Deep-research reports on records, as leads for curators |
| `docs/`, `mkdocs.yml` | The documentation site: guides, plus schema pages generated by LinkML |
| `conf/site.yaml` | How the documentation site and record browser look: colors, theme, columns |
| `pages/` | Generated record browser |
| `registry/goatmech.md` | Draft entry for MechRegistry |
| `.claude/skills/` | Curation skills for agents |
| `.github/workflows/` | GitHub workflows; `docs/WORKFLOWS.md` describes them |

## Use

```bash
just install
just qc
just validate data/goat_breeds/<record>.yaml
just docs-serve     # browse the documentation locally
```

The documentation is published at
https://monarch-initiative.github.io/mechmaker/example/goatmech/.

## Validation

Validation checks three things. The record matches the schema, with unknown
fields rejected. Every ontology term exists, sits under the right root and
carries its real label. Every quoted snippet appears verbatim in its cited
source.

Validation does not check that the science is right. GoatMech is
AI-curated. Treat it as a curated draft reviewed by people, not as an
authority.
