# News leads

One file per record, written by `just news-leads <record>`: the searches
run, how many hits each had, and the most promising leads of each, with
archived copies where one exists.

These are leads, never evidence. Never cite a file here. Read the story's
archived copy and quote it with `just add-evidence`. The `news-leads` skill
says how, and how to tune the searches in `conf/news.yaml`.

Commit a leads file with the records it served: it shows what was searched
and when.
